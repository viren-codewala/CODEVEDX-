# Student Performance Prediction System

> **AI/ML Internship Project 2 -- CODEVEDX**

------------------------------------------------------------------------

## Project Overview

The **Student Performance Prediction System** is a Python-based Machine
Learning application developed as part of the **CODEVEDX AI/ML
Internship**. The application analyzes student academic information and
predicts final examination performance using a Machine Learning model.
It demonstrates data handling, visualization, model training,
evaluation, and prediction through a menu-driven console application.

------------------------------------------------------------------------
